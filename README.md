# Raid Messaoui — LinkTree

A fast, mobile-first LinkTree page designed to match the dark-cyan PVC business card for **Raid Messaoui — Software Solutions Developer**.

## Tech Stack
- Pure static **HTML5 / CSS3 / Vanilla JS** — zero build step, instant load time for QR/NFC scans, and native **GitHub Pages** compatibility.

## Deploy to GitHub Pages
1. Push this repository to GitHub.
2. Open your repository **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Select your branch (e.g. `main`) and folder `/ (root)`, then click **Save**.
5. Your page will be live at `https://<your-username>.github.io/<repo-name>/` (or your custom domain if configured).
